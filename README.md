## 🚀 How It Works (Automated with LeetSync)
What makes this repository unique is its seamless integration with LeetSync. Instead of manually copying, formatting, and pasting code after every successful submission, the LeetSync browser extension automatically handles the workflow:

   1. I solve a problem and hit Submit on LeetCode.
   2. Upon receiving an "Accepted" status, LeetSync automatically captures the solution.
   3. The extension instantly commits and pushes the code directly to this GitHub repository.

This powerful automation allows me to focus 100% of my energy on breaking down complex problems and writing clean, efficient code, while keeping my professional development portfolio updated in real-time.
